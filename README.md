# Rackup Support

Rackup is an iPhone word-game companion. Its first rollout is being prepared for TestFlight; a public beta link is not available yet.

- [Get help](SUPPORT.md)
- [Privacy policy](PRIVACY.md)
- [Report a bug or ask a question](https://github.com/tylergannon/rackup-support/issues/new)

This is a public support forum. Do not post private screenshots, payment information, credentials, or other sensitive information. Apple handles App Store purchases and refunds.
